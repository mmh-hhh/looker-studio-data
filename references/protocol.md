# Looker Studio 取数协议

这份文档只给需要排障或扩展运行脚本的 agent 使用。业务用户不需要阅读。

## 支持范围

本 skill 读取用户本人有权访问、且所有者允许下载的 Looker Studio 报表。

页面主要使用三个接口：

- `getReport`：报表、页面、组件和下载权限；
- `getSchema`：字段名称和类型；
- `batchedDataV2`：图表查询与数据结果。

这些图表接口不是 Google 公布的稳定数据 API。接口变化时必须失败关闭，不能返回空文件或部分结果。

## 登录模型

首选同机专用、持久的浏览器 profile。自动选择顺序是 Chrome、Edge、Chromium；已有 Chrome 时优先使用已验证的 Chrome 路径。用户日常使用什么浏览器不构成前提。

登录只从 `https://datastudio.google.com/` 开始。用户本人在打开的浏览器窗口中输入账号、密码、MFA 和验证码；运行脚本只在登录完成后复用状态。

私密文件：

- profile：`0700`；
- `auth-state.json`：`0600`，包含敏感 Cookie 和浏览器存储；
- `login-state.json`：`0600`，只保存入口路径；
- catalog、capture、recipe、metadata：`0600`，不得包含 Cookie 或授权头。

`login-state.json` 记录首次成功使用的浏览器类型，后续优先保持一致。不要假设 profile 或 auth-state 可以跨机器使用；Google 的设备和浏览器安全绑定可能让跨机状态失效。

## 发现流程

1. 打开指定报表页面；
2. 读取 `getReport`，确认当前访问权和 `downloadable`；
3. 读取 `getSchema`，把内部字段映射为业务名称；
4. 捕获当前页面成功的 `batchedDataV2` 请求和响应；
5. 生成只含元数据的 catalog；
6. 把可选报表和筛选项交给用户确认。

capture 可以保存无凭证的请求模板，但不能保存数据响应、Cookie 或授权头。

## 原生请求与普通回放

2026-07-24 的私有报表验证证明：

- 页面原生 `batchedDataV2` 请求返回 200；
- 相同 URL、Cookie、请求体和可见请求头由普通 `fetch` 发送时可能返回 HTTP 400；
- 因此不能假设所有私有报表都支持合成请求回放。

一次性导出应优先使用页面已经成功返回的原生响应。若后续分页回放被拒绝、页面仍允许下载且已有图表总行数，可使用图表自身的“导出数据 → CSV”流程，并将 CSV 行数与图表总数核对。该 UI 回退只用于一次性导出，不能保存为定时配方。只有真实验证通过后，才使用保存的请求做回放、日期改写或分页。

同一透视表可能连续返回：

- 快照壳：0 行，但声明总数；
- 主数据 `row0`：实际完整数据；
- `TotalOfTotal`：汇总行。

选择顺序必须优先主数据响应，不能用“最后一个响应”代替主数据。等待条件应是目标组件出现可用主数据，而不是任意数据请求出现。

## 筛选

日期筛选只有在请求中存在明确的开始和结束字段时才能改写。无法识别就停止，让用户在页面设置日期后重新发现。

维度筛选优先通过页面语义控件设置一次，再捕获新的成功请求。不要猜测私有筛选表达式。

筛选项列表可能是虚拟滚动或数据源截断结果。除非接口给出完整总数，否则只能标记为预览。

## 导出与完整性

导出流程：

1. 选择用户确认的组件；
2. 获取该组件可用的主数据响应；
3. 解析 `tableDataset` 的字段和列式数据；
4. 有分页信息时继续到 `totalCount`；
5. 写 UTF-8 CSV；
6. 写选择条件、行数和 SHA-256 元数据；
7. 对比实际行数与接口总数。

没有 `totalCount` 时，不能声称已证明全量，只能说明接口返回了一个非分页响应。

## 失败处理

| 现象 | 处理 |
|---|---|
| 跳到登录页 | 让用户本人重新登录 |
| 无权访问 | 停止，申请正常权限 |
| `downloadable: false` | 只展示目录，不抓数据 |
| 找不到组件请求 | 打开对应页面后重新 catalog |
| 日期结构未知 | 页面设置日期后重新 catalog |
| 普通回放 HTTP 400 | 使用原生成功响应；重复任务暂不判定可用 |
| 原生下载菜单不可识别或 CSV 行数不等于总数 | 停止，不交付文件；提示用户可在浏览器手动下载 |
| 行数小于 `totalCount` | 停止，不交付部分文件 |
| 响应结构变化 | 保留错误与组件 ID，更新解析器后重新验证 |

任何失败都不能退化为截图、DOM 文字或仅导出当前可见行。
